# KLH-FED-2026-Session8-Batch-3-DDCA
# Design and Simulation of 8-bit Signed Binary Number Representation Using Sign-Magnitude Method

## Project Overview
This repository contains the project submission for the **Digital Design and Computer Architecture (DDCA)** course, developed during **Session 8** by **Batch 3**

The core focus of this project is the design, implementation, and simulation of an **8-bit Signed Binary Number Representation system** utilizing the **Sign-Magnitude method**. The system effectively segregates the Most Significant Bit (MSB) as the sign indicator (0 for positive, 1 for negative) while utilizing the remaining 7 bits to represent the absolute magnitude of the number.

## Repository Contents
* **`DDCA project.pptx`** – Detailed presentation covering the framework, logic design workflow, and simulation outcomes.
* **`DDCA assignment.pdf`** – Analysis of the 8-bit sign-magnitude representation.
* **`.circ` Files** – Logisim files.
